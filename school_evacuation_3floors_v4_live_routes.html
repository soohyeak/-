시뮬레이터 사용 안내
PC와 태블릿 조작
PC에서는 WASD 또는 방향키로 이동합니다. 마우스를 누른 채 드래그하면 둘러볼 수 있습니다. ‘추가 설정 → 마우스 잠금’을 사용하면 마우스를 누르지 않아도 회전하며, Esc로 해제합니다. F는 손전등, L은 정전, T는 온도, C는 방화문, M은 전체 지도, P는 일시정지입니다.
태블릿에서는 왼쪽 조이스틱을 원하는 방향으로 밀어 이동하고, 다른 손가락으로 화면 오른쪽을 드래그해 시점을 회전합니다. 두 동작은 동시에 사용할 수 있습니다. 계단도 조이스틱으로 직접 걸어 오르내립니다. 화면이 느리면 ‘추가 설정 → 가벼움’으로 바꾸세요.
실시간 경로 변화 훈련 (05)
처음 실행하면 진행형 가상 훈련이 선택됩니다. 3층 첫 갈림길에 접근하면 고온 상황이 생기고 짧은 연결 복도로 우회합니다. 동측 계단으로 2층에 도착하면 2층↔1층 연결부가 통제되어 그 층에서 서측 계단으로 변경합니다. 서측 계단으로 1층에 도착하면 후문이 폐쇄되어 1층 복도를 통해 정문으로 안내합니다. 사건 때 위치는 초기화되지 않습니다. 이 순서는 시연용이며 실제 센서 측정이나 연기 확산 예측이 아닙니다.
화면 하단에서 다음 이동 방향을 확인하세요. 초록색 안내선 위 밝은 화살표는 진행 방향으로 흐릅니다. 경로가 바뀌면 지도에 이전 경로를 11초간 회색 점선으로 비교 표시합니다. ‘실시간 경로 판단’에서 변경 이유와 두 출구의 후보 거리를 확인할 수 있습니다. 재탐색 횟수와 실제 경로 변경 횟수는 별도 집계합니다.
기존 수동 상황 버튼이나 새 구간 통제를 사용하면 자유 실험으로 전환됩니다. USB 자동 제어 중에는 진행형 가상 사건을 발생시키지 않습니다. 기존 센서의 입력 형식과 위치 매핑은 그대로입니다. 05를 다시 선택하면 출발점에서 진행형 훈련을 다시 시작합니다.
학교 구조와 대피
3층은 일반 교실·과학실·컴퓨터실·음악실·연구실, 2층은 일반 교실·보건실·도서실·학생자치실, 1층은 교무실·행정실·시청각실·급식실·로비를 갖췄습니다. 설계도와 같은 양쪽 계단을 사용하며, 복도에는 꺾임과 남측 우회 통로를 더했습니다.
3층 중앙 복도에서 출발합니다. 녹색 안내선을 따라 1층 정문 또는 후문 바깥의 대피 구역까지 이동하세요. 위험 구역은 피하고 통행 불가 구역은 제외하여 전체 3개 층의 경로를 계산합니다. ‘두 출구 모두 폐쇄’에서는 경로가 없다는 경고를 표시합니다. 위험 구역 안에 있으면 탈출 경로를 먼저 계산하며, 위험 표현 자체가 보이지 않는 물리적 벽이 되지는 않습니다.
USB 센서 연결
지원되는 데스크톱 브라우저에서 USB 연결 버튼을 누르고 아두이노 포트를 선택하세요. HTTPS 또는 localhost 같은 보안 컨텍스트가 필요합니다. 파일 직접 실행의 포트 사용 여부는 브라우저 정책에 따라 달라질 수 있습니다. Arduino IDE의 시리얼 모니터를 먼저 닫으세요. 태블릿 USB 연결은 지원 여부가 기기·브라우저에 따라 달라 보장하지 않습니다.
기존 센서 필드 이름과 115200 baud를 유지했습니다. 다음과 같이 한 줄 JSON과 줄바꿈을 보내면 됩니다.
{"sound":242,"lightRaw":180,"temperature":24.6,"tilt":false,"button":false,"proximity":false}
소리sound, 선택 soundDetected · 245 감지 / 238 해제
조도darkMode 우선, 또는 lightRaw 280 이상 암전 / 260 이하 복귀, lightPct도 지원
온도temperature · 23℃ 주의 / 29℃ 위험. 복귀는 1℃ 여유. 센서 오류값 85, -127 제외
기울기tilt의 감지 시작 시 방화문 폐쇄. 플레이어가 문 위에 있으면 벗어난 뒤 폐쇄
버튼button 누름 전환마다 방화문 개방 / 폐쇄
근접proximity boolean 또는 cm 값 표시
‘센서로 상황 자동 제어’를 켜야 센서가 재난 상태를 바꿉니다. 수동 상황 버튼·시나리오·초기화 사용 시 자동 제어는 꺼지지만 USB 수신과 수치 표시는 유지됩니다. 수신 중단·온도 오류 시 마지막 위험 상태를 자동으로 정상 처리하지 않으며, 상태를 확인한 뒤 수동 초기화하세요. 새 데이터가 5초간 없으면 오래된 값으로 표시합니다.
구현과 범위
외부 이미지·폰트·3D 라이브러리를 다운로드하지 않는 단일 HTML입니다. 3D 공간은 WebGL로, 미니맵은 독립된 2D Canvas로 그립니다. 경로는 층별 보행 영역과 계단 연결을 합친 가중 그래프에서 계산합니다. 짧은 거리뿐 아니라 주의 구역 비용과 위험 구역 회피를 반영하지만 연기 확산·군중·실제 화재 물리 모형은 포함하지 않습니다.
기울기 입력은 짧은 가상 흔들림과 현재 안내 경로 밖의 잔해 발생을 시작합니다. 피해 위치는 시뮬레이터가 선택하며 실제 감지 위치가 아닙니다. 정상 복귀 후에도 잔해가 남습니다. 상황 제어의 「기울기 · 가상 피해」에서 USB 없이 시연하거나 잔해를 복구할 수 있습니다.
학교 배치·계단·센서 임계값은 프로젝트 시연용입니다. 실제 건물 설계나 법정 피난 기준을 검증한 자료가 아닙니다.
